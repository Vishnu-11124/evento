# 🎉 Evento

**Find. Explore. Attend.**

Evento is a modern event discovery platform that helps users find exciting events, connect with communities, and stay updated with what's happening around them—all in one place.

Whether you're looking for tech meetups, workshops, conferences, cultural events, or community gatherings, Evento makes discovering and attending events simple and seamless.

---

## ✨ Features

* 🔍 Discover upcoming events
* 📍 Explore events by category and location
* 👥 Connect with communities and organizers
* 📅 View event details and schedules
* ❤️ Save and manage favorite events
* 📱 Responsive and modern user interface

---

## 🚀 Tech Stack

* **Frontend:** Next.js 16, React 19, TypeScript
* **Styling:** Tailwind CSS
* **Backend:** Next.js Server Components & API Routes
* **Database:** MongoDB
* **Authentication:** NextAuth.js / JWT (planned)

## 📦 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js (v18 or later)
* npm, yarn, pnpm, or bun

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd evento
```

Install dependencies:

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
